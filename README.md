# jamms desktop tamagotchi!

a tiny desktop companion built with HTML, CSS, JavaScript, and Electron. pick a character and something it needs (food, energy, water...), and keep it alive!

the full setup steps and milestones are in the assignment doc

## what each file does

| file | what it's for |
| --- | --- |
| `index.html` | what's on the screen (your character, meter, buttons) |
| `style.css` | how it looks (colors, fonts, layout, animations) |
| `script.js` | how it behaves (clicks, timers, moods) |
| `main.js` | opens the Electron window. you'll only change small stuff here, like the window size |
| `package.json` | project settings. tells npm the app needs Electron and what `npm start` does |

`node_modules/` and `package-lock.json` show up after `npm install`. don't touch them!
